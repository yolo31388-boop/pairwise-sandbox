# 游戏内脚本沙箱与安全执行系统

## 项目描述

游戏内脚本沙箱与安全执行系统的bug修复项目。核心模块 `security/sandbox.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 沙箱创建完全没做脚本能访问服务器所有文件
- 权限控制完全没做普通玩家也能删服务器数据
- 资源限制完全没做脚本可无限占用CPU和内存
- 代码分析完全没做危险代码也能执行
- 执行超时完全没做死循环永远执行

## 运行测试

```bash
python -m pytest tests/test_sandbox.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
